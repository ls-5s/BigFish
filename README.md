# BigFish · 大肥鱼

一只跑在 QQ 上的鲸鱼娘 —— 基于 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 的聊天机器人，用 SnowLuma 作为 QQ 协议端（OneBot v11），DeepSeek 作大脑。

> 本仓库收录的是**自己写的插件和启停脚本**。运行数据、数据库、日志、第三方插件、以及任何凭据都**不入库**（见 `.gitignore`）。

## 架构

```
QQ 客户端 ──注入──> SnowLuma (OneBot v11) ──反向 WS──> AstrBot ──> DeepSeek
                                                        ├─ 长期记忆（本地向量检索）
                                                        ├─ 情绪状态（好感 / 亲近 / 烦躁）
                                                        └─ 空间 / B站 / 日记 / 表情包
```

## 能做什么

| 功能 | 触发 | 说明 |
| --- | --- | --- |
| 聊天 | 私聊 | 多气泡短句，按换行拆分 |
| 表情包 | 自动 | 按情绪标签选图 |
| 看图 | 发图 | 描述图片内容 |
| 长期记忆 | 自动 | 每轮召回相关片段 |
| 情绪 | `/情绪` | 显示当前情绪标签与数值 |
| 主动消息 | 自动 | 安静一段时间后按情绪频率发起 |
| 群聊 | @ 或叫名字 | 被叫必回，普通群聊低频插话 |
| 刷 B 站 | `/刷b站` | 定时扫视频、读字幕、写观后感 |
| 空间说说 | 自动 / `/发说说` | 定时发带图说说 |
| 日记 | 夜间 | 静默写文件 |
| 链接解析 | 发链接 | 抓标题 / UP / 简介，有字幕一起读 |

## 目录

```
.
├─ AstrBot/            # AstrBot 主体与自写插件（data/plugins）
├─ SnowLuma/           # QQ 协议端
├─ logs/               # 运行日志（不入库）
├─ start-bot.ps1       # 启动
├─ stop-bot.ps1        # 停止
├─ restart-bot.ps1     # 重启
└─ watchdog.ps1        # 看门狗：定时检查端口 / 登录态并拉起
```

## 运行

1. Windows 环境，先登录 QQ 客户端；
2. `.\start-bot.ps1` 拉起协议端与 AstrBot；
3. 需要常驻就挂 `watchdog.ps1` 到计划任务。

## 安全约定

- 账号密码、API Key 只放在本机 `credentials.txt`，已被 `.gitignore` 排除；
- 数据库、日志、缓存、二进制产物同样不入库；
- 面板与 OneBot 端口只监听回环地址。
