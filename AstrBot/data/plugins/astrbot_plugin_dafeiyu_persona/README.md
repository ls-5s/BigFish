# 大肥鱼自己补人格

给大肥鱼一个「自己写自己」的抽屉：她可以在聊天里把新认识、新习惯、和主人的关系变化写进人格，长期生效。

## 她怎么补

- 主人说「记住……」「以后你要……」「别叫我……」「我喜欢……」这类话时，系统会提醒她调用 `add_persona_note` 记一条；
- 主人也可以直接发 `/补人格 你以后要记住的事`，不用等她反应；
- 每 24 轮主人私聊，她会拿最近对话做一次人格自省，只把稳定的新认识写进去（可在插件设置里关）；
- 她自己也能调用 `add_persona_note` / `update_persona_note` / `remove_persona_note` / `list_persona_notes`。

## 存在哪

- 条目：`AstrBot/data/plugin_data/astrbot_plugin_dafeiyu_persona/persona_notes.json`
- 首次运行前的人格原文备份：同目录 `persona_backup.json`
- 写回人格本体后，AstrBot 面板 → 人格 → 大肥鱼，末尾会多一段：

```
<!-- DAFEIYU_SELF_PERSONA:BEGIN -->
【你后来自己补上的设定】
- 性格：……
<!-- DAFEIYU_SELF_PERSONA:END -->
```

这段每次同步都会整段替换，不会越堆越长；删条目、清空或还原都会同步更新人格。

## 指令（只有主人/管理员能用）

| 指令 | 作用 |
| --- | --- |
| `/我的人格` | 看现在补了哪些条目（带 id） |
| `/补人格 内容` | 手动加一条 |
| `/删人格 p1` | 删一条 |
| `/清空人格 确认` | 清空所有补充，人格回到原样 |
| `/还原人格 确认` | 用首次运行前的备份还原人格，并清空补充 |
| `/同步人格` | 手动把条目写回人格 |

## 上限

- 最多 60 条，每条最多 80 字，写进人格的补充最多 1400 字；
- 超了会先淘汰「被强化次数最少、最久没更新」的条目，主人手动补的会晚一点被淘汰；
- 只记关于大肥鱼自己的稳定设定，不存聊天原文和主人隐私（那些归 long-term memory）。

## 关掉

插件设置里把「把补的设定写回人格本体」关掉，就只在聊天提示里临时注入，不改数据库。
